# ТОК — сайт сервиса компьютеров и сетей

Готовый демонстрационный сайт для локального бизнеса: ремонт компьютеров, сети и IT-поддержка небольших офисов. Русский язык, статическая сборка, без фреймворков и внешних API.

Это портфолио-проект: название, контакты, адрес и цены вымышлены. Дисклеймер об этом есть в футере.

## Что внутри

- Сдержанная редакционная типографика: Literata + Golos Text + JetBrains Mono (шрифты лежат локально, Google Fonts не нужен).
- Секции: hero, ключевые условия, каталог услуг, интерактивный калькулятор, процесс работы, FAQ, контакты и заявка.
- Калькулятор пересчитывает смету по выбранным услугам, учитывает срочность (+30%) и выезд (+500 ₽), переносит расчёт в форму.
- Заявка без бэкенда: валидация, сборка текста, открытие Telegram с готовым сообщением, копирование в буфер как fallback.
- Мобильное меню на нативном `<dialog>`, доступные контролы, видимый фокус, `aria-live` для сметы и статусов, поддержка `prefers-reduced-motion`.
- Метаданные: title, description, canonical, Open Graph, Twitter Card, favicon (SVG + PNG), apple-touch-icon, OG-изображение.

## Стек

- HTML, CSS, нативный JavaScript (ES-модули).
- Node.js только для сборки и проверок. **Ноль npm-зависимостей.**
- Сборка рендерит данные из `src/content.js` в статический HTML — контент виден без JavaScript и индексируется поисковиками.

Требуется Node.js 20+.

## Быстрый старт

```bash
npm run build   # собрать dist/
npm start       # собрать и открыть http://127.0.0.1:4173
```

Другие команды:

```bash
npm run preview   # отдать уже собранный dist/ без пересборки
npm test          # юнит-тесты логики расчёта и заявки
npm run check     # сборка + тесты + статическая валидация
```

`npm run check` проверяет: якоря, `aria-*`-ссылки, локальные ассеты, шрифты из CSS, label у полей, метаданные, ссылки `target="_blank"`, остатки шаблонных токенов и синтаксис JS.

## Как кастомизировать под другой бизнес

1. Откройте `src/content.js`.
2. Замените:
   - `business` — название, город, title/description, URL, дисклеймер;
   - `contacts` — телефон (`tel:`-ссылка отдельно), Telegram, почту, адрес, часы;
   - `pricing` — цену диагностики и пояснения к смете;
   - `extras` — выезд мастера и надбавку за срочность;
   - `services` — названия, описания, цены, сроки. `subscription: true` исключает услугу из разового калькулятора;
   - `process`, `faq`, `form` — тексты процесса, правил и формы.
3. Пересоберите сайт: `npm run build`.

Все контактные ссылки в шапке, меню, контактах, футере и заявке генерируются из `contacts`. Telegram-ссылка заявки собирается как `https://t.me/<handle>?text=<сообщение>`; проверьте, что бот/аккаунт принимает такие ссылки, и протестируйте на телефоне.

Чтобы сменить визуальный стиль, правьте токены в начале `src/assets/css/styles.css` (`--paper`, `--ink`, `--copper`, шрифты, ширина контейнера). Чтобы поменять favicon/OG, замените файлы в `src/assets/img/`.

Для нового бизнеса также обновите `og:image` и canonical: `business.siteUrl` в конфиге.

## Как работает заявка

1. Пользователь заполняет имя, телефон/Telegram, комментарий и подтверждает согласие.
2. JS валидирует поля, собирает текст с выбранными услугами и ориентиром из калькулятора.
3. Открывается Telegram с подставленным текстом; одновременно появляется блок с готовым сообщением.
4. Кнопка «Скопировать текст» использует Clipboard API, а при его отсутствии — запасной `execCommand('copy')`. Если скопировать не удалось, текст выделяется для ручного копирования.
5. Данные никуда не отправляются: сервера нет. Сообщение уходит только после нажатия «Отправить» в Telegram.

Ограничение: без JavaScript форма не отправится — в разметке есть `<noscript>`-подсказка с телефоном и Telegram.

## Деплой

Сайт полностью статический. После `npm run build` выложите содержимое `dist/` на любой хостинг:

- **Netlify / Vercel / Cloudflare Pages:** build command `npm run build`, publish directory `dist`.
- **GitHub Pages:** соберите локально и опубликуйте `dist/` (например, через `gh-pages` или Actions с `npm ci && npm run build`).
- **Обычный хостинг / nginx:** загрузите файлы из `dist/`, точку входа — `index.html`.

Обновите canonical и OG-URL в `src/content.js` на реальный домен перед публикацией.

## Доступность и качество

- Семантические `header/main/section/footer`, один `h1`, ссылки-пропуски.
- Все поля формы связаны с `label`; ошибки выводятся текстом, фокусируются и связаны через `aria-describedby`; сводка ошибок — `role="alert"`.
- Калькулятор озвучивает изменения через `aria-live="polite"`; выбранные услуги доступны с клавиатуры.
- Мобильное меню — нативный модальный `<dialog>` с ловушкой фокуса и закрытием по Escape.
- Анимации отключаются при `prefers-reduced-motion`.
- Нет внешних запросов, рекламных трекеров и платных API.

## Лицензии

Шрифты Literata, Golos Text и JetBrains Mono распространяются по SIL Open Font License 1.1; файл лицензии — `src/assets/fonts/OFL.txt`, он попадает в `dist/assets/fonts/`. Исходные начертания взяты из Google Fonts и Self-hosted локально.

## Демонстрационные данные

Телефон, адрес, e-mail и Telegram — вымышленные. Домен `tok-service.example` зарезервирован для примеров. Цены и обещания по срокам/гарантии — часть демонстрационного сценария, а не реальные обязательства.
